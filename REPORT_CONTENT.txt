LOGHEALTH – LOG ANALYTICS AND SYSTEM HEALTH INTELLIGENCE

1. Title
LogHealth – Log Analytics and System Health Intelligence

2. What’s your website do?
LogHealth is a log analytics and system health intelligence platform that transforms application logs into actionable insights about reliability, operational health, anomalies, and system behavior.
It provides an explainable 0–100 system health score, component-level failure tracking, statistical anomaly detection (volume spikes & error bursts), evidence-based prioritized risk ranking, historical baseline comparisons, and exportable executive health reports.

3. Frontend
Modern HTML5, Vanilla CSS3, and JavaScript dashboard with a dark command-center aesthetic, responsive layout, glassmorphic panels, and 10 dedicated views:
- Overview (Health Score Gauge, KPI cards, executive summary, anomaly alert banner)
- Analytics (Chart.js timeline, severity doughnut, component distribution)
- Components (Subsystem failure rates, event volumes, and evidence-based risk levels)
- Anomalies (Statistical z-score volume spikes, critical bursts, subsystem failure concentrations)
- Risk Assessment (Prioritized concerns, evidence, affected subsystems, and operational mitigations)
- History (Full event audit trail with search and severity filtering)
- Reports (Executive 10-section intelligence report viewer with Markdown export and copy tools)
- Ingest / Upload (Drag-and-drop file ingestion, manual log paste, and parser simulator)
- API Docs (Complete OpenAPI-style interactive endpoint documentation)
- System Settings (Database connectivity, formula breakdown, and environment info)

4. Backend Architecture
Log Ingestion (JSON Format A/B, Syslog, Web Logs, Raw Text) → Ingestion & Parsing Engine (Normalization & Deduplication) → Subsystem Classification (Database, Auth, Network, API, Background Jobs, Infrastructure, Memory, File System, Application) → Evidence-Based Health Scoring (Weighted severity, error density, anomaly penalties) → Anomaly Detection Engine → Component Risk Assessment → Historical Baseline Comparison → Executive Report Generator → JSON REST API & Responsive Dashboard

5. Hosting & Deployment
- Production: Deployed on Vercel Serverless (configured with dynamic `/tmp` storage for ephemeral execution, with extensible support for external PostgreSQL/Supabase/Neon databases via DATABASE_PATH for durable multi-tenant persistence).
- Local Development: Flask server at http://127.0.0.1:5000 using SQLite with WAL mode and indexed queries.
