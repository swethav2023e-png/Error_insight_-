ERRORINSIGHT – INTELLIGENT ERROR ANALYZER

1. Title
ErrorInsight – Intelligent Error Analyzer

2. What’s your website do?
ErrorInsight analyzes the errors.json file generated by a Log File Parser and identifies error types, frequency, and severity.
It detects recurring problems and provides possible causes and recommended solutions through an interactive dashboard.

3. Frontend
HTML, CSS and JavaScript. The dashboard provides colorful summary cards, charts, recurring errors, recommendations and recent logs.

4. Backend Architecture
errors.json → Flask Backend → JSON Processing → Error Categorization → Frequency & Severity Analysis → Recurring Error Detection → Recommendation Engine → JSON Response → Dashboard

5. Hosting
No. The application is currently running locally using the Flask development server at http://127.0.0.1:5000.
